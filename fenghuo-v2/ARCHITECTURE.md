# 烽火谋局：模块版

先搭框架，再实现函数。`../fenghuo/` 的旧版源码保留，不覆盖、不删除。

## 依赖与职责

| 模块 | 职责 | 对外接口 |
| --- | --- | --- |
| `src/data.mjs` | 武将与卡牌定义 | `HEROES`, `CARDS`, `getHero` |
| `src/game.mjs` | 游戏状态、初始化、牌堆、存档验证 | `Game` |
| `src/cards.mjs` | 目标验证、打牌、伤害、自救 | `cardActions` |
| `src/turns.mjs` | 回合、弃牌、胜负 | `turnActions` |
| `src/skills.mjs` | 技能验证、技能结算 | `skillActions` |
| `src/ai.mjs` | 选择合法行动、执行一步 | `aiActions` |
| `src/storage.mjs` | 独立存档、偏好、战绩 | `storage` |
| `src/ui.mjs` | 界面与用户事件 | 页面控制器 |

规则模块不访问 DOM、网络、本地存储，也不操作定时器。界面调用统一规则引擎，AI 和玩家使用同一套合法性检查。AI 只能根据自己的牌与场上公开信息选行动。

状态机：`play`（出牌）→ `discard`（必要时弃牌）→ 下一名存活武将；任何结算中一方全灭则进入 `over`。一轮包含所有存活武将的行动。

## 实施顺序

1. 页面、样式入口与各模块导出框架。
2. 定义武将、卡牌、牌堆与状态。
3. 补充卡牌、伤害、技能与回合函数。
4. 实现 AI，再连接操作界面和存档。
5. 自动化规则测试、手机与桌面浏览器实测、离线测试。

## 版本边界

旧版入口：`../fenghuo/`。新版入口：`./`。新版存档键以 `fenghuo.v2.` 开头，不覆盖旧版存档。两个版本都属于原创单机四人明阵 2v2 游戏，不包含联网对战。
