# game-hub
游戏仓

## 烽火谋局

原创四人明阵策略卡牌网页游戏。你与一名 AI 友军对抗两名 AI 敌将。
灵感来自阵营卡牌桌游，不使用《三国杀》官方商标、角色美术、音频或源码，也不是其官方版本。

- 6 名原创武将、12 类卡牌、84 张牌堆。
- 主动与被动技能、自动闪避、护甲、对决、濒死自救、弃牌、胜负判断。
- 规则驱动的 AI，共用玩家规则，不读取敌人手牌内容。
- 移动端、平板及桌面布局；自动存档、可选合成音效、AI 倍速。
- PWA 主屏安装与离线缓存，无登录、无统计上报、无付费、无外部资源依赖。
- 当前为**单机 2v2 明阵版**，不包含真人联网、隐藏身份、联机房间。

新版入口：`fenghuo-v2/index.html`。游戏库入口：`index.html`。

按「保留前面的代码，先写框架再写函数」的要求，旧版全部保留在 `fenghuo/`。新版先建立页面和模块接口，再接入状态、卡牌、回合、技能、AI、存档和 UI 函数。两个版本的存档相互独立；新版复用旧版样式但不修改旧版文件。

模块设计说明见 [`fenghuo-v2/ARCHITECTURE.md`](fenghuo-v2/ARCHITECTURE.md)。

### 通过 GitHub Pages 游玩

仓库 Settings → Pages → Build and deployment：

1. Source 选择 **Deploy from a branch**。
2. Branch 选择 **main**，目录选择 **/ (root)**，点击 Save。
3. 等待 GitHub 显示部署成功。默认游戏库地址为 `https://fullmeta1.github.io/game-hub/`，新版游戏地址为 `https://fullmeta1.github.io/game-hub/fenghuo-v2/`。在启用 Pages 前，这两个网址不会提供游戏。

不需要构建，也不需要配置付费服务。若 Pages 已启用，后续提交将由 GitHub 自动更新。

iPhone / iPad 请在 Safari 中打开，点分享 → 添加到主屏幕。安卓在 Chrome 菜单选择安装或添加到主屏幕。首次联网完整打开后可离线玩。存档只保存在当前浏览器；桌面版可能使用独立存储，清除网站数据会丢失存档。

### 本地运行与测试

安装 Node.js 18+，无需安装依赖：

```sh
npm start
# 打开 http://127.0.0.1:4173/
npm test
```

新版使用 ES 模块，需要通过本地服务器或 GitHub Pages 打开。旧版 `fenghuo/index.html` 支持直接用浏览器打开，但文件预览器可能禁用脚本，且离线缓存和主屏安装需要 HTTP(S)。

### 简要规则

开局每人四张手牌，玩家先行。回合开始摸两张牌（沈知微摸三张）。先选牌，再选目标，确认出牌。每回合通常限一次破阵，顾长风可出两次。结束回合时将手牌弃至当前体力数，最低保留一张。

闪避自动应对破阵与箭雨；护甲抵消伤害；军医在濒死时自动自救。全队退场则败，玩家退场后可观战队友。第 20 轮起，每位武将回合开始失去一点体力（无视护甲，可自救），防止无限拖延。武将技能、卡牌说明可在游戏「玩法」中查看。

### 项目结构

```text
index.html             游戏库首页
fenghuo/               烽火谋局独立目录
  engine.js            纯规则引擎 / AI / 存档校验
  app.js               界面、交互、本地存档
  style.css            响应式界面
  sw.js                离线缓存
fenghuo-v2/            新版（旧版代码保留）
  ARCHITECTURE.md       框架与模块职责
  src/data.mjs          武将和卡牌数据
  src/game.mjs          状态、牌堆和规则入口
  src/cards.mjs         出牌与伤害
  src/turns.mjs         回合和弃牌
  src/skills.mjs        武将技能
  src/ai.mjs            AI 决策
  src/storage.mjs       独立存档
  src/ui.mjs            界面事件
tests/engine.test.mjs   规则回归与批量对局测试
scripts/serve.js        零依赖本地预览服务器
```

新增游戏时建议每款游戏一个目录，并在首页增加入口。更新缓存资源时同时升级 `sw.js` 内的缓存版本号。
